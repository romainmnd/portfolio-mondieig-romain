Veille technologique

Sujet : l'impact de l'intelligence artificielle sur le développement informatique.

Ma veille technologique consiste à suivre les évolutions de l'intelligence artificielle et à comprendre les changements qu'elle apporte dans le métier de développeur.

Présentation du sujet

L'intelligence artificielle prend une place de plus en plus importante dans le domaine informatique. Elle permet notamment de générer du code, d'expliquer des erreurs, d'aider à déboguer un programme et d'accompagner la création d'applications.

J'ai choisi ce sujet car il concerne directement ma formation en BTS SIO option SLAM et mon futur métier dans le développement logiciel. Il est important de comprendre ces nouveaux outils, leurs avantages mais également leurs limites.

Problématique

Comment l'intelligence artificielle transforme-t-elle le métier de développeur et les méthodes de développement logiciel ?

Objectifs de ma veille

  • Suivre les nouveautés liées à l'intelligence artificielle.
  • Découvrir les nouveaux outils destinés aux développeurs.
  • Comprendre comment l'IA peut améliorer la productivité.
  • Identifier les limites et les risques du code généré par l'IA.
  • Comprendre comment le métier de développeur évolue.

Actualité 1 – Les assistants de code IA en entreprise

Titre : Usage, Effects and Requirements for AI Coding Assistants in the Enterprise: An Empirical Study

Source : arXiv (IBM Research)

Date : 27 janvier 2026

Résumé : Des chercheurs d'IBM ont interrogé 57 développeurs de profils variés sur leur utilisation des assistants de code basés sur l'IA. L'étude compare les usages, mesure l'efficacité perçue et son effet sur la productivité et la qualité, puis en déduit les besoins pour les futurs outils.

Intérêt : Cette étude montre comment les assistants IA sont réellement utilisés dans des projets professionnels, et pas seulement dans des démonstrations. Elle est directement liée à ma problématique sur l'évolution des méthodes de développement.

Mon avis : Cela correspond à ce que j'ai vécu avec Claude Code pendant mon stage : l'outil fait gagner du temps, mais il faut bien expliquer le besoin et vérifier le résultat. L'échantillon reste petit (57 personnes), donc je garde un regard prudent sur les conclusions.

Lien : arxiv.org/abs/2601.20112

Actualité 2 – L'IA dans le quotidien des développeurs

Titre : Evolving with AI: A Longitudinal Analysis of Developer Logs

Source : IEEE/ACM ICSE 2026 (version disponible sur arXiv)

Date : Avril 2026 (conférence ICSE 2026)

Résumé : Cette étude analyse pendant deux ans les données d'utilisation de l'environnement de développement de 800 développeurs, dont 400 utilisent l'IA et 400 non. Ces données sont complétées par un sondage auprès de 62 professionnels. Les chercheurs regardent l'impact de l'IA sur la productivité, la qualité du code et la façon d'éditer le code.

Intérêt : Beaucoup d'avis sur l'IA reposent sur des impressions personnelles. Ici, les conclusions s'appuient sur des données mesurées sur une longue durée, ce qui les rend plus fiables.

Mon avis : Je trouve intéressant que l'étude compare ce que les développeurs font réellement avec ce qu'ils pensent faire. Cela confirme qu'il faut tester et mesurer plutôt que de croire que l'IA est forcément plus efficace.

Lien : arxiv.org/abs/2601.10258

Actualité 3 – Le développeur devient superviseur

Titre : The Impact of AI Coding Assistants on Software Engineering: A Longitudinal Study

Source : arXiv (Université d'Auckland)

Date : 22 mai 2026

Résumé : Deux chercheurs ont suivi 95 ingénieurs logiciels pendant six mois grâce à deux questionnaires. Ils constatent que le travail se déplace de l'écriture du code vers la vérification et la supervision de ce que produit l'IA. Environ 84 % des participants estiment que l'IA améliore leur productivité, mais l'expérience de travail ne progresse pas de la même façon : c'est ce que les auteurs appellent le « paradoxe productivité-expérience ».

Intérêt : Cette publication répond directement à ma problématique : elle montre que le métier de développeur change, avec plus de contrôle et de relecture, et moins d'écriture de code.

Mon avis : C'est exactement ce que j'ai ressenti en stage : je passais beaucoup de temps à tester, relire et corriger le code proposé. Cela confirme qu'il est important de bien comprendre le code, même quand c'est l'IA qui le génère. Les résultats viennent de réponses déclarées par des volontaires, donc ils ne sont pas valables pour tous les développeurs.

Lien : arxiv.org/abs/2605.23135

Les principaux thèmes étudiés

Génération de code

L'IA peut proposer du code à partir d'une consigne écrite. Elle peut aider à créer des fonctions, des pages web ou des structures de programmes.

Aide au débogage

Certains outils peuvent analyser du code, expliquer des erreurs et proposer des corrections. Le développeur doit cependant vérifier que les solutions proposées fonctionnent réellement.

Évolution du métier de développeur

Le développeur doit apprendre à utiliser ces nouveaux outils, mais aussi savoir comprendre le code, formuler correctement ses demandes et contrôler les résultats obtenus.

Limites de l'intelligence artificielle

L'IA peut produire des erreurs, proposer du code peu sécurisé ou ne pas comprendre précisément un besoin. Elle ne remplace donc pas les connaissances et les vérifications du développeur.

Bilan de ma veille

Cette veille me permet de suivre les évolutions de l'intelligence artificielle dans le développement informatique et de découvrir de nouveaux outils.

J'ai également pu constater l'utilité de ces technologies pendant mon stage aux Francas de Pau, où j'ai utilisé Claude Code pour m'accompagner dans un projet de développement web.

Cette expérience m'a montré que l'intelligence artificielle peut faire gagner du temps, mais qu'il reste indispensable de comprendre le code produit, de le tester et de vérifier les résultats.

Je souhaite continuer cette veille afin de suivre les prochaines évolutions et de mieux comprendre leur impact sur le métier de développeur.
